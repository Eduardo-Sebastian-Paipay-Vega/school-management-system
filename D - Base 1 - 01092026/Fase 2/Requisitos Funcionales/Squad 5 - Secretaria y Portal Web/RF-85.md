# RF-85: Publicación en la Página Oficial de Facebook y Feed Integrado en el Portal

## 1. Enunciado Normativo Formal (IEEE 830 / ISO 29148)

> **El sistema deberá permitir compartir automáticamente las noticias publicadas (RF-84) en la página oficial de Facebook del colegio mediante la API oficial de Meta (Graph API), y mostrar en el portal las publicaciones recientes de esa página. No se realizará scraping de Facebook.**

---

## 2. Flujo Operativo y Especificación Funcional

* **Precondiciones:**  
  - Página oficial de Facebook del colegio conectada por un administrador de la página, con permisos otorgados mediante el flujo oficial de Meta.

* **Entradas:**  
  - Noticia publicada y marcada como 'Compartir en Facebook'.
  - Token de página guardado de forma cifrada.

* **Proceso y Lógica de Negocio:**  
  1. Al publicar la noticia, el sistema crea la publicación en la página con el resumen, la imagen de portada y el enlace a la noticia del portal.
  2. Guarda el identificador de la publicación de Facebook y su estado.
  3. Ante un fallo de la API (token vencido o límite de uso), reintenta y avisa a Comunicaciones.
  4. El portal muestra el feed de la página mediante el complemento oficial de Meta, sin almacenar datos de terceros.

* **Salidas:**  
  Noticia compartida en Facebook con enlace al portal, y feed visible en el portal.

* **Postcondiciones:**  
  La difusión llega a la comunidad en Facebook y el tráfico vuelve al portal oficial.

---

## 3. Criterios de Aceptación (Gherkin / DoD)

```gherkin
Escenario: Token vencido
  Dado que el token de la página de Facebook venció
  Cuando se publica una noticia marcada para compartir
  Entonces la noticia se publica igual en el portal
  Y Comunicaciones recibe un aviso para reconectar la página
```
