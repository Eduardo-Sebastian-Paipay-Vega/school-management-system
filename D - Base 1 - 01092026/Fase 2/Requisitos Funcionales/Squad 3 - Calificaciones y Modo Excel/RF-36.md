## 1. Enunciado Normativo Formal (IEEE 830 / ISO 29148)

> **El sistema deberá permitir a los docentes definir instrumentos de evaluación, criterios de rúbricas y pesos porcentuales vinculados a las competencias curriculares del CNEB.**

---

## 2. Flujo Operativo y Especificación Funcional

* **Precondiciones:**  
  - Cursos asignados al docente en el periodo activo.

* **Entradas:**  
  - El docente ingresa a 'Calificaciones > Estructura de Evaluación'.
  - Selecciona el curso, grado y sección.
  - Añade una nueva columna de evaluación indicando el nombre (ej. Práctica 1, Examen Bimestral).
  - Selecciona la competencia CNEB a la cual contribuye la evaluación.
  - Define la escala a utilizar (Vigesimal 0-20 o Literal CNEB).
  - Guarda la estructura.

* **Proceso y Lógica de Negocio:**  
  1. El docente ingresa a 'Calificaciones > Estructura de Evaluación'.
  2. Selecciona el curso, grado y sección.
  3. Añade una nueva columna de evaluación indicando el nombre (ej. Práctica 1, Examen Bimestral).
  4. Selecciona la competencia CNEB a la cual contribuye la evaluación.
  5. Define la escala a utilizar (Vigesimal 0-20 o Literal CNEB).
  6. Guarda la estructura.
  7. El sistema habilita las columnas en la planilla matricial.

* **Reglas de Negocio:**  
  - RN-NOT-02: Toda evaluación debe tributar a una de las competencias oficiales de la asignatura.

* **Salidas:**  
  El sistema habilita las columnas en la planilla matricial.

* **Postcondiciones:**  
  Estructura de columnas de evaluación creada para la planilla de notas.

* **Excepciones:**  
  - 3a. Carga de estructura predefinida: Opción de copiar la estructura de evaluaciones de un bimestre anterior en un solo clic.
