## 1. Enunciado Normativo Formal (IEEE 830 / ISO 29148)

> **El sistema deberá ofrecer a los estudiantes y padres de familia una interfaz web y móvil para consultar sus notas publicadas, retroalimentación del docente y estado de aprobación.**

---

## 2. Flujo Operativo y Especificación Funcional

* **Precondiciones:**  
  - Usuario estudiante o apoderado autenticado con sesión activa.

* **Entradas:**  
  - El estudiante o apoderado ingresa a la opción 'Mis Calificaciones'.
  - Selecciona el Bimestre a consultar.
  - Cada asignatura muestra su nivel de logro alcanzado (AD, A, B, C) con su color representativo.
  - Al hacer clic en un curso, se despliegan las competencias evaluadas, la conclusión formativa del docente y las recomendaciones para mejorar.

* **Proceso y Lógica de Negocio:**  
  1. El estudiante o apoderado ingresa a la opción 'Mis Calificaciones'.
  2. Selecciona el Bimestre a consultar.
  3. El sistema presenta la libreta virtual con la lista de asignaturas.
  4. Cada asignatura muestra su nivel de logro alcanzado (AD, A, B, C) con su color representativo.
  5. Al hacer clic en un curso, se despliegan las competencias evaluadas, la conclusión formativa del docente y las recomendaciones para mejorar.

* **Reglas de Negocio:**  
  - RN-NOT-12: Aislamiento estricto de privacidad entre estudiantes conforme a la Ley de Protección de Datos Personales.

* **Salidas:**  
  El sistema presenta la libreta virtual con la lista de asignaturas.

* **Postcondiciones:**  
  Visualización clara de las notas bimestrales por curso con sus respectivas conclusiones descriptivas.

* **Excepciones:**  
  - 4a. Notas aún no publicadas por el docente: Se muestra la insignia 'En Evaluación'.
