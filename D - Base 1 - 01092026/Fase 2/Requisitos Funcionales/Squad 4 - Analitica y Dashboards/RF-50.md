## 1. Enunciado Normativo Formal (IEEE 830 / ISO 29148)

> **El sistema deberá contrastar el desempeño de secciones paralelas del mismo grado identificando brechas pedagógicas y áreas curriculares críticas.**

---

## 2. Flujo Operativo y Especificación Funcional

* **Precondiciones:**  
  - Notas cerradas o en proceso en las secciones a comparar.

* **Entradas:**  
  - El coordinador accede a 'Analítica > Comparador de Secciones'.
  - Selecciona el Grado (ej. 4° de Secundaria) y las secciones 'A', 'B' y 'C'.
  - Selecciona el área curricular (ej. Matemática).
  - El coordinador identifica la sección que requiere reforzamiento o nivelación docente.

* **Proceso y Lógica de Negocio:**  
  1. El coordinador accede a 'Analítica > Comparador de Secciones'.
  2. Selecciona el Grado (ej. 4° de Secundaria) y las secciones 'A', 'B' y 'C'.
  3. Selecciona el área curricular (ej. Matemática).
  4. El sistema procesa y genera gráficos de barras apiladas mostrando el porcentaje de AD, A, B y C de cada aula.
  5. El coordinador identifica la sección que requiere reforzamiento o nivelación docente.

* **Reglas de Negocio:**  
  - RN-ANA-04: Las métricas deben expresarse tanto en cantidad absoluta de estudiantes como en porcentaje relativo.

* **Salidas:**  
  El sistema procesa y genera gráficos de barras apiladas mostrando el porcentaje de AD, A, B y C de cada aula.

* **Postcondiciones:**  
  Gráficos comparativos lado a lado con cálculo de brecha porcentual.

* **Excepciones:**  
  - 3a. Comparativa de promedios históricos: Opción para superponer el desempeño del año anterior.
