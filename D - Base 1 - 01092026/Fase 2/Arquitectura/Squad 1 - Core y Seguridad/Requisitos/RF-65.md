## 1. Enunciado Normativo Formal (IEEE 830 / ISO 29148)

> **El sistema deberá interceptar y registrar de forma inmutable todas las operaciones de creación, modificación, eliminación y acceso sensible en la tabla logs_auditoria, capturando usuario_id, accion, tabla_afectada, registro_id, direccion_ip, user_agent, payload_anterior y payload_nuevo con marca de tiempo UTC.**

---

## 2. Flujo Operativo y Especificación Funcional

* **Precondiciones:**  
  Cualquier petición de mutación ejecutada en el backend.

* **Entradas:**  
  Transacción HTTP entrante y contexto de seguridad del usuario autenticado.

* **Proceso y Lógica de Negocio:**  
  1. El middleware AuditInterceptor captura los datos antes y después del commit en PostgreSQL. 2. Escribe el registro en la partición de auditoría. 3. Aplica restricción que impide UPDATE o DELETE sobre la tabla de logs.

* **Salidas:**  
  Registro de auditoría persistido inmutablemente.

* **Postcondiciones:**  
  Trazabilidad completa asegurada para fines legales y peritaje informático.
