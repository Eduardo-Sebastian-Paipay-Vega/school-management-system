## 1. Enunciado Normativo Formal (IEEE 830 / ISO 29148)

> **El sistema deberá gobernar el acceso a cada endpoint y pantalla mediante una matriz de Control de Acceso Basado en Roles (RBAC), distinguiendo 5 perfiles normativos: SuperAdmin, Directivo, Docente, Estudiante/Apoderado y Portería/Auxiliar.**

---

## 2. Flujo Operativo y Especificación Funcional

* **Precondiciones:**  
  Usuario autenticado con uno o más roles asignados en el token JWT.

* **Entradas:**  
  Petición HTTP entrante con token de autorización en la cabecera.

* **Proceso y Lógica de Negocio:**  
  1. El middleware interceptor decodifica el token. 2. Comprueba si los roles del usuario satisfacen los permisos requeridos por el recurso. 3. Bloquea peticiones no autorizadas.

* **Salidas:**  
  Respuesta HTTP 200 OK con datos si tiene permiso, o HTTP 403 Forbidden si carece de privilegios.

* **Postcondiciones:**  
  Intento de acceso denegado registrado en el log de seguridad.
