# RF-64: Exportación de Datos en Formatos Estándar Abiertos (PDF y Excel SIAGIE)

**Módulo:** Módulo 11: Emisión de Reportes y Verificación QR

**Prioridad:** Esencial  
**Rama de Trabajo:** `feature/squad-5/reports-crypto`  

---

## 1. Enunciado Normativo Formal (IEEE 830 / ISO 29148)

> **El sistema deberá permitir exportar los listados y calificaciones a hojas de cálculo Microsoft Excel (.xlsx) estructuradas de forma compatible con la plataforma SIAGIE del MINEDU.**

---

## 2. Flujo Operativo y Especificación Funcional

* **Precondiciones:**  
  - Información académica registrada en el sistema.

* **Entradas:**  
  - El operador de secretaría ingresa a 'Exportaciones > Compatibilidad SIAGIE'.
  - Selecciona el tipo de plantilla a generar (ej. 'Nómina de Matrícula' o 'Calificaciones Finales').
  - Selecciona Grado y Sección.
  - Descarga el archivo Excel normalizado.
  - El operador ingresa al portal del MINEDU y sube el archivo generado exitosamente.

* **Proceso y Lógica de Negocio:**  
  1. El operador de secretaría ingresa a 'Exportaciones > Compatibilidad SIAGIE'.
  2. Selecciona el tipo de plantilla a generar (ej. 'Nómina de Matrícula' o 'Calificaciones Finales').
  3. Selecciona Grado y Sección.
  4. El sistema extrae los datos y los acomoda en la estructura oficial de celdas requerida por SIAGIE.
  5. Descarga el archivo Excel normalizado.
  6. El operador ingresa al portal del MINEDU y sube el archivo generado exitosamente.

* **Reglas de Negocio:**  
  - RN-REP-07: Respetar estrictamente los códigos de asignaturas y formatos de fecha que exige el software del MINEDU.

* **Salidas:**  
  El sistema extrae los datos y los acomoda en la estructura oficial de celdas requerida por SIAGIE.

* **Postcondiciones:**  
  Archivo XLSX generado listo para ser cargado en el portal del SIAGIE sin errores de sintaxis.

* **Excepciones:**  
  - 4a. Advertencia de datos faltantes: Si algún estudiante no tiene DNI registrado o nota completa, el sistema le alerta antes de generar el archivo.
