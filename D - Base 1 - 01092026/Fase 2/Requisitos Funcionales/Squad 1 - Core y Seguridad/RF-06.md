# RF-06: Importación Masiva de Usuarios desde Archivos Excel / CSV

---

## 1. Enunciado Normativo Formal (IEEE 830 / ISO 29148)

> **El sistema deberá procesar archivos estructurados en formato Microsoft Excel (.xlsx) y CSV para el alta masiva de estudiantes y docentes, ejecutando una pre-validación sintáctica, reportando filas con inconsistencias y realizando inserciones transaccionales por lotes.**

---

## 2. Flujo Operativo y Especificación Funcional

* **Precondiciones:**  
  Archivo de plantilla descargado previamente con columnas reglamentarias.

* **Entradas:**  
  Archivo Excel o CSV cargado desde la interfaz de administración.

* **Proceso y Lógica de Negocio:**  
  1. Lee archivo en streaming. 2. Valida estructura de columnas. 3. Valida datos fila por fila (DNI 8 dígitos, correos válidos). 4. Inserta registros válidos en transacción PostgreSQL. 5. Genera reporte de filas erróneas.

* **Salidas:**  
  Resumen cuantitativo (ej: 145 usuarios importados con éxito, 3 rechazados por DNI inválido).

* **Postcondiciones:**  
  Nuevas cuentas listas para operar en el año lectivo.
